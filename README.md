# 🏟️ Sport Booking System

A web-based application for booking sports facilities such as football fields, basketball courts, badminton courts, and other sports venues.
The system allows users to view available time slots, make reservations, and manage bookings online.

---

## 📌 Features

### 👤 User

* Register and log in to the system
* View available sports facilities
* Check available time slots
* Book sports facilities
* Cancel bookings
* View booking history
* Display real-time availability of sports fields for the upcoming hour

### 🛠️ Admin

* Manage sports facilities
* Manage booking schedules
* View all reservations
* Manage users

---


## 🛠️ Technologies Used

* React / Vue

### Backend

* Node.js

### Database

* MySQL 

### Dev Tools

* Docker
* Git
* REST API

---


### Install frontend dependencies

```
cd frontend
npm install
npm run dev
```

---

###  Install backend dependencies

```
cd backend
npm install
npm run start:dev
```

---



## 📊 Example Workflow

1. User logs into the system
2. User selects a sports facility
3. System shows available time slots
4. User selects a time slot
5. User confirms the booking
6. System records the reservation
