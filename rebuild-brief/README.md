# Rebuild Brief

เอกสารชุดนี้ใช้ประกอบการจ้างพัฒนาระบบจองสนามกีฬา KMUTNB ใหม่ เขียนขึ้นจากการตรวจสอบโค้ดจริงของระบบเดิม (`backend/`, `frontend/`) ไม่ใช่แค่จากเอกสารข้อเสนอโครงการ จึงมีรายละเอียดเชิงเทคนิคที่เอกสารข้อเสนอเดิมไม่มี

อ่านคู่กับ `../เอกสารข้อเสนอโครงการ_จองสนาม_ปรับปรุง.md` ซึ่งเป็นสเปกความต้องการเชิงธุรกิจ (scope, timeline, feature list ตาม role) — เอกสารในโฟลเดอร์นี้เสริมเฉพาะส่วนที่เอกสารนั้นไม่ได้ลงรายละเอียด

| ไฟล์ | เนื้อหา |
|---|---|
| [`00-project-name.md`](./00-project-name.md) | ตัวเลือกชื่อโปรเจกต์ |
| [`01-data-model.md`](./01-data-model.md) | โครงสร้างข้อมูลจริง (entities, enum สถานะ, กฎเชิงธุรกิจเรื่อง capacity) |
| [`02-lessons-learned.md`](./02-lessons-learned.md) | บั๊ก/pattern ปัญหาที่พบจริงในระบบเดิม และวิธีป้องกันไม่ให้เกิดซ้ำ — ควรให้ทีมพัฒนาใหม่อ่านก่อนเริ่มงาน |

ถ้าต้องการดูตัวอย่าง look and feel เดิม ดูที่ `../style-guide.md` (design tokens, สี, spacing ที่ระบบเดิมใช้)
